# Persisty — instaladores

Este repositório guarda só os instaladores do [Persisty](https://persisty.app), um por versão, em [Releases](../../releases). O código não fica aqui.

- **Baixar a versão mais recente:** https://persisty.app/download
- **Todas as versões, com data e SHA-256:** https://persisty.app/download/versions
- **O que mudou em cada versão:** https://persisty.app/changelog

## Conferir um arquivo

Baixe também o `SHA256SUMS.txt` da mesma versão e rode, na pasta dos dois:

```sh
shasum -a 256 -c SHA256SUMS.txt --ignore-missing
```
